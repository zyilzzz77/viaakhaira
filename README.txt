KLINIK GIGI VIRDYA - VERSI HTML BIASA

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka file index.html menggunakan browser.

Struktur file:
- index.html              : Isi dan struktur halaman.
- css/base.css            : Warna, font, header, dan footer.
- css/components.css      : Komponen kartu, kamera, hasil, dan formulir.
- css/responsive.css      : Tampilan HP dan aksesibilitas animasi.
- js/food-data.js         : Database makanan dan minuman.
- js/app.js               : Kamera, upload foto, dan analisis makanan.

Catatan kamera:
Beberapa browser hanya mengizinkan kamera jika website dibuka melalui HTTPS
atau localhost. Fitur upload foto tetap dapat dipakai saat index.html dibuka
langsung.

Catatan kesehatan:
Fitur foto hanya memeriksa kualitas gambar dan tidak mendiagnosis penyakit.
